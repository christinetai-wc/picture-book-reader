# 繪本跟念

《我會想・我會說》繪本互動版：聽示範 → 小孩跟著念 → 念對 80% 自動翻頁。插畫依原書重畫並加上小動畫（經作者同意）。

- 目前完成：《天黑了》
- 技術：純前端 HTML/CSS/JS、Canvas 繪圖、Web Speech API（語音辨識／合成）、pinyin-pro（拼音比對）
- 使用：需用 https 網址開啟（iPad Safari 或 Android Chrome）；iPad 要在設定開啟「Siri 與聽寫」，第一次會詢問麥克風權限
- 本機預覽：`python3 -m http.server 8765 --directory app`，開 http://localhost:8765
